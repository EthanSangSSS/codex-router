# Code of Conduct

## Our standard

Contributors and maintainers are expected to keep project interactions professional, respectful, and focused on improving the work.

Constructive disagreement is welcome. Harassment, threats, discriminatory language, deliberate disruption, publication of another person's private information, or sustained personal attacks are not acceptable.

## Scope

This standard applies in repository issues, pull requests, reviews, discussions, and other project spaces where someone is representing this project.

## Engineering discussion

Technical criticism should address code, evidence, design, tests, documentation, or project decisions rather than the person making them. Security concerns and suspected vulnerabilities should follow `SECURITY.md` instead of being disclosed in a public issue.

## Enforcement

Maintainers may edit or remove contributions that violate this standard and may temporarily or permanently restrict participation when necessary to protect the project community.

For conduct concerns that should not be handled publicly, contact the maintainer privately using a contact method published on the repository owner's GitHub profile. Reports will be reviewed in good faith and with reasonable confidentiality.
